Banking Application
Overview
This is a banking application that allows users to create accounts, deposit money, withdraw money, and transfer funds to other users. The application utilizes Firebase Real-time Database to store user data and transaction history.

Features
Account Creation: Users can create an account by entering personal details.

Deposit: Users can deposit money into their account.

Withdraw: Users can withdraw money from their account.

Transfer: Users can transfer money to other users.

Transaction History: Every transaction (deposit, withdrawal, or transfer) is logged and displayed in the transaction history.

Firebase Integration: The application uses Firebase Real-time Database for storing and retrieving user data and transaction history.
